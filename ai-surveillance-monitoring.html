✅ Why This Architecture Works

Distributed Processing: Edge nodes handle AI inference locally, reducing central server load by 90%+.
Redundancy: Each edge node covers half the cameras; if one fails, the other continues.
Scalability: Add more edge nodes or upgrade to QCS8550 for 100+ cameras.
Radar Integration: Edge nodes receive radar data via Ethernet, fuse with camera feeds for vehicle tracking.

⚠️ Radar + Camera Fusion

For true sensor fusion (combined tracking), use Jetson Orin with ROS2 or NVIDIA Isaac ROS. Entry/mid-tier platforms (RK3588, QCS8550) work best with radar as a separate alert trigger rather than fused tracking — the edge node receives radar events via MQTT/Ethernet and correlates with camera zones.
